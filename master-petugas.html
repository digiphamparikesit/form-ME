ℹ️ Cara Tambah Petugas:
  1. Buka Supabase Dashboard → Authentication → Users → Add User
  2. Isi email: <username>@me.local (mis. budi@me.local)
  3. Set password awal, centang Auto Confirm User
  4. Copy User UID yang muncul
  5. Kembali ke sini, klik Tambah Petugas, paste UID-nya
